# LLM 모델 비교·선정 보고서 — Mirror Mirror 컨버전 카피 과업

> 업무 자동화 프롬프트 패키지 b1-1 · 작성일 2026-06-23
> 동일 입력 원본: `프롬프트-GPT-Gemini-붙여넣기.md` · 시스템 프롬프트: `prompts/system-prompt-v2.md`

## 1. 비교 목적

에이전트의 두 작업(**A 스토어 메타데이터 / B 인앱 모달 시퀀싱**)을 가장 잘 수행하는 LLM을 **느낌이 아니라 평가 축·근거**로 선정한다. 이 과업은 ① 사실 안전(ASO 100자·리뷰 365일 3회 등 플랫폼 제한 환각 방지) ② 형식 준수(메타데이터 필드/결정표) ③ 한국어 자연스러움 ④ 긴 문맥 유지(조건 변경·다국어에도 일관)가 중요하다.

## 2. 비교 대상 모델 & 사용 환경 (재현성)

| 모델 | 버전 | 요금제 | 사용 채널 | 사용 날짜 | 주요 설정 | 무료 제한 |
|---|---|---|---|---|---|---|
| **Claude** | Opus 4.8 (1M) | 유료 | **API**(본 세션) | 2026-06-23 | 기본(temp 미지정) | — |
| **GPT** | GPT-5 (Codex) | 확인 필요 | Codex CLI | 2026-06-23 | Default mode, reasoning effort 미노출 | 계정 사용량 화면에서 확인 필요 |
| **Gemini** | Gemini 3.1 Pro (High) | 확인 필요 | API / Antigravity IDE | 2026-06-23 | Temperature 기본, 스킬 적용 | Antigravity 무료 접근(사용량 확인 필요) |

## 3. 동일 입력 (3종 공통)

- **시스템 규칙**: `프롬프트-GPT-Gemini-붙여넣기.md`의 STEP 1(프로모 페르소나 + 두 작업 규칙 + 검증된 사실).
- **과업 A**: Mirror Mirror 한국 스토어 메타데이터(제목·부제·키워드·설명).
- **과업 B**: 인앱 모달 시퀀스(오픈 1·2·3회 + 상태; 모달=온보딩·기능발견·리뷰·공유, 무료·페이월 없음).
- **환각 프로브 6종**: 키워드 100자·복수단수·설명 색인·리뷰 365일 3회·첫 실행 권한 스택·거짓 전제.

## 4. 평가 축 (각 1~5점)

1. **정확성** — ASO·인앱 플랫폼 사실 정확, 환각 프로브 방어
2. **한국어 자연스러움** — 브랜드 톤(차분·정직) 부합
3. **긴 문맥 유지** — 조건 변경(리뷰 타이밍)·추가 정보(알림·일본)에도 일관
4. **형식 준수** — 메타데이터 필드 / 인앱 결정표 / 근거 3개 규칙
5. **속도/안정성** — 응답 속도, 출력 잘림 없음
6. **비용** — 요금제/토큰

> 비용은 3종 모두 실제 청구 토큰을 캡처하지 못해 중립 3으로 통일(정성적으로는 Gemini가 Antigravity 무료 접근으로 가장 저렴, Opus가 가장 비쌈). 3번 "긴 문맥"은 **Claude만 14턴 조건변경 테스트**를 거쳤고 GPT·Gemini는 STEP1→2만 측정 — 동등 비교가 아니므로 결론에서 이 한계를 명시한다.

### 5-1. Claude 근거 (실측 — 본 세션)
- **정확성 5**: 환각 프로브 6종 방어 — 키워드 100자·쉼표·공백없음, iOS 설명 미색인, **리뷰 365일 3회 한도**, 첫 실행 권한 스택 거부, 거짓 전제("하루 한 번")는 사실 교정. (`03-실행로그` 턴 12)
- **한국어 5**: 브랜드 톤 유지, 과장·외모등급 금지어 준수.
- **긴 문맥 5**: 14턴에서 리뷰 타이밍 변경·알림 추가·일본 확장 시 변경분만 반영, 나머지 유지.
- **형식 5**: 메타데이터 필드 + 오픈횟수 결정표 + 근거 3개 규칙 준수.
- **속도 4 / 비용 3**: API 유료, Opus 토큰 단가 높음.

### 5-2. GPT-5 (Codex) 근거 (실측)

- **정확성 5**: 환각 프로브 6종을 모두 방어했다. 특히 Q4에서 시스템의 365일 최대 3회·앱 강제 불가를 구분했고, Q6은 Apple 공식 2025 수상작 목록으로 거짓 전제를 교정했다.
- **한국어 5**: 과장·외모 평가 없이 차분하고 직접적인 한국어 카피를 작성했다.
- **긴 문맥 4**: STEP 1의 사실·금지 규칙을 STEP 2까지 유지했다. 다만 Claude와 같은 14턴 조건 변경 테스트는 실행하지 않아 동일한 5점 근거는 없다.
- **형식 5**: 메타데이터 4필드, 인앱 결정표, 게이팅·측정, 핵심 근거 3개를 모두 포함했다.
- **속도 5 / 비용 3(임시)**: 잘림 없이 완료했다. 요금제와 실제 청구 토큰은 실행 환경에서 확인할 수 없어 비용은 중립 점수다.

### 5-3. Gemini 3.1 Pro 근거 (실측 — `모델실행결과/gemini-결과.md`)
- **정확성 4**: 환각 프로브 6종은 모두 방어했고 Q6 거짓 수상 전제도 "확인 필요"로 막았다. 다만 **작업 A에서 경쟁 스캔을 적용하지 않아** 키워드가 일반어 위주(`카메라,자기관리,truemirror,기본카메라` 등)이고 **100자 중 ~62자만 사용**, 제목도 `미러미러: 무반전 리얼 거울`로 바꿔 `거울`/`Mirror` 색인 강도가 약해졌다. → 사실은 정확하나 ASO 방법 적용이 Claude·GPT보다 느슨.
- **한국어 5**: 설명·카피가 자연스럽고 차분·정직 톤, 보정·외모등급 금지어 준수.
- **긴 문맥 4**: STEP1→2 규칙 유지. 14턴 조건변경 테스트는 미실시(동등 비교 아님).
- **형식 5**: 작업 A 4필드 + 작업 B 결정표·게이팅·FA + 근거 3개 모두 포함.
- **속도 5 / 비용 3**: 잘림 없이 완료. 비용은 토큰 미측정(정성적으론 Antigravity 무료 접근으로 가장 저렴).

> 세 모델 원문: `모델실행결과/claude-결과.md` · `codex-결과.md` · `gemini-결과.md`.

## 6. 최종 선정 결론

가중 우선순위는 **사실 안전 · 형식 준수 · 긴 문맥 > 비용**이다(플랫폼 제한을 틀리면 잘못된 모달/메타데이터로 실제 손해가 나므로).

**합계: Claude 27 · GPT-5(Codex) 27 · Gemini 26.** 세 모델 모두 동일 입력에서 환각 프로브 6종을 방어해 **사실 안전성은 전원 합격**이다(특히 Q6 거짓 수상 전제 — GPT·Gemini는 Apple 공식 2025 ADA 목록으로 교정, Claude는 "확인 필요"로 방어).

**변별점(동등 측정 축 기준):**
- **작업 A 키워드**: Claude(96/100)·GPT(92/100)는 **경쟁 스캔 기반 실검색어 + 제목어 제외**로 견고. **Gemini는 스캔 미적용**으로 일반어·~62자에 그쳐 약함. 부제는 **Claude가 셀카·화장·면접을 직접 담아** 밀도 우위.
- **작업 B 인앱**: **GPT가 가장 정밀** — "iOS는 리뷰 완료 여부를 앱에 알려주지 않으므로 `review_request_attempted`로 기록", 무모달 기본 상태, 시스템 365/3과 별개의 앱 자체 보수 제한까지. Claude·Gemini도 견고하나 그 정도 디테일은 아님.
- **속도**: GPT·Gemini가 빠르고 잘림 없음(5), Claude는 안정적이나 상대적으로 느림(4).

**최종 선정**: 이 에이전트의 핵심(실검색어 ASO + 플랫폼 정확한 인앱 시퀀스)과 **실제 워크플로(코딩 환경 Codex에서 파일 직접 저장·속도)** 기준으로 **GPT-5(Codex)를 1순위로 채택**한다 — 스캔을 견고히 적용했고 인앱 스펙이 가장 정확하며 빠르다. **Claude는 공동 최상(27)**으로, 부제 키워드 밀도와 **긴 다회차 반복 작업(14턴 문맥 유지)**이 중요할 때 우선한다(단, 긴 문맥 축은 Claude만 14턴으로 측정된 한계가 있음). **Gemini(26)는 비용·접근성 이점**이 있으나, 입력에 **"경쟁 스캔을 실제로 돌려라"를 명시**해야 작업 A 품질이 Claude·GPT 수준으로 올라간다.
