# 거부불가 배포 검증

검증일: 2026-10-11. 서비스: https://geobulga.vercel.app

## 현재 확인한 결과

| 항목 | 결과 |
| --- | --- |
| Vercel Python 3.12 빌드 | 성공 |
| 로그인 없는 홈 접근 | HTTP 200 |
| 홈·편지 만들기·사용법·소개 메뉴 | 4개 섹션 정상 전환 |
| 데스크톱 1440px | 4개 섹션 모두 가로 넘침 없음 |

| 최종 편지 생성 → 저장 → 공유 링크 | 최종 코드 자동 배포 후 확인 예정 |
| 최종 AI 결과·공유 화면 캡처 | 최종 검증 후 추가 예정 |

초기 점검에서 남아 있던 타래공방 URL은 실제 배포가 없었고, 작업 폴더의
거부불가 코드를 배포 대상으로 수정했다. 초기 Upstash 설정은 DNS 연결에
실패해 사용자가 새 환경 변수를 등록했다. GPT 인증 오류는 사용자 결정에 따라
Claude 단일 공급자로 정리했다.

최종 동작 확인 전에는 편지 공유 기능까지 완료됐다고 표시하지 않는다.

## 검증 방법

- 브라우저에서 실제 서비스 URL에 접속해 메뉴와 입력 폼을 조작한다.
- 데스크톱 `1440 × 1000`과 모바일 `390 × 844`에서
  `document.documentElement.scrollWidth === document.documentElement.clientWidth`를 확인한다.
- 정상 입력으로 AI 편지를 만든 뒤, 생성된 주소를 별도 브라우저에서 열어
  서버 저장과 조회를 확인한다.
- 빈 입력, 긴 입력, 잘못된 JSON, 잘못된 HTTP 메서드, 없는 링크에 대한 실패 안내를 확인한다.
- API 키가 보이는 환경 파일이나 터미널 출력은 캡처하지 않는다.
