## 2. 검색어 성격 (실측 — 왜 한국은 '거울' 중심인가)

- `거울`(kr) 상위 10: **Photo & Video 5** 등 → 얼굴 거울 의도 **깨끗**.
- `mirror`(kr) 상위 10: **Utilities 3 (화면 미러링: ApowerMirror·Chromecast 등)** 혼입 → 영어 mirror는 한국에서 **screen-mirroring과 경쟁**, 비효율.
- **결론**: 한국은 `거울 / 손거울`이 주력, `mirror`는 보조. (단순 번역이었다면 놓쳤을 차이)

## 3. 키워드 필드 교체안 (iOS 키워드 필드)

규칙 준수: **100자 이내 / 쉼표 구분 / 쉼표 뒤 공백 없음 / 제목·부제에 이미 쓴 단어 제외(중복 색인 낭비) / 복수·단수 한쪽만.**

```
손거울,셀카,셀피,화장,메이크업,화장고침,대칭,비대칭,표정,표정연습,면접,소개팅,헤어,앞머리,고화질,줌,확대,무반전,화장확인,눈썹,치아,몸단장,데이트,프사,증명사진,표정관리
```

- **글자 수: 96 / 100** (검증 완료)
- **포함 근거(실측)**: 경쟁사 제목·설명에서 반복 — 셀카·화장·메이크업·대칭·비대칭·고화질·줌·확대·헤어·손거울. 여기에 사용자 상황어 — 면접·소개팅·증명사진·데이트·프사 추가.
- **제외 단어**: 거울·Mirror·좌우·반전(제목) / 진짜·얼굴(부제) — 이미 색인되므로 키워드 필드에서 빼 글자 수 절약.

## 4. 제목·부제 최적화안 (선택 — 브랜드 vs ASO 트레이드오프)

- **부제 개선안(권장)**: `셀카·화장·면접 전, 남들이 보는 진짜 얼굴` (약 24자) — **셀카·화장·면접** 키워드를 부제(색인 대상)에 직접 추가하면서 브랜드 메시지 유지.
- **제목**: 브랜드 정체성 유지 권장. ASO를 더 밀고 싶다면 `거울 · Mirror · 무반전 셀카·화장거울` 같이 연결어("나를 동시에")를 검색어로 치환 가능. → 브랜드팀 판단 사항.

## 5. iOS vs Google Play (출시 채널별 키워드 전략 차이)

- **iOS**: 검색 색인 = 이름 + 부제 + 키워드 필드. 설명은 색인 안 됨 → 위 3번/4번이 핵심.
- **Google Play(동시 출시 시)**: 제목 + 짧은 설명(80자) + **긴 설명(4000자)이 모두 색인** → 위 키워드(손거울·셀카·화장·대칭·면접 등)를 **설명 본문에 자연스럽게 녹여** 작성해야 한다. iOS 설명을 그대로 복붙하면 Play 검색 노출을 놓친다.

## 6. 다른 로케일 확장 시 (동일 절차)

`prompts/system-prompt-v2.md`의 **App Store 로케일 레퍼런스 표**를 시드로, 각 시장에서 (현지어 + mirror) 2종 검색 → 상위 앱 제목·설명 스캔 → 장르 혼입 진단 → 키워드 도출을 반복한다. 예: JP는 `鏡/ミラー`(Health & Fitness, 깨끗) 중심, US/EN은 `mirror`에 selfie/real/makeup 한정어 결합.
