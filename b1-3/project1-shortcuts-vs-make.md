# Project 1 — 자동화 도구 비교 구현: Apple 단축어 vs Make

> **워크플로우**: "매일 정해진 시각 → 조건 분기(평일/주말) → 카카오톡 '나에게 보내기'로 자동 전송"
> 동일한 워크플로우 구조를 **Apple 단축어(Shortcuts)** 와 **Make** 두 도구로 구현하고 비교한다.

---

## 1. 무엇을 자동화했나

매일 아침 직접 GA(Google Analytics)를 열어 어제 지표를 확인하고, 잊지 않으려 메모를 남기는 루틴이 있었다. 한 번에 3분이지만 매일 반복되고 시간도 들쭉날쭉했다. 이걸 **정해진 시각에 카카오톡 '나와의 채팅'으로 자동으로 꽂히게** 만들었다.

- **평일**: 어제 GA 핵심 1줄(총 사용자·다운로드)을 받는다.
- **주말**: 지표 대신 간단한 리마인더 문구를 받는다.

핵심 발견부터 적으면 — **단축어와 Make는 같은 카카오 '나에게 보내기' REST API를 호출**한다. 차이는 **그 HTTP 호출이 어디서 실행되느냐**다. 단축어는 내 기기(로컬), Make는 클라우드(24시간 서버). 채널·API가 동일하므로 "실행 환경"만 바꿔 끼운 순수 비교가 된다.

## 2. 워크플로우 구조 (두 도구 공통)

```
[Trigger] 매일 지정 시각
   │   단축어 → 개인 자동화 "특정 시각" (즉시 실행)
   │   Make   → Schedule 트리거 (매일 HH:MM)
   │
   ├─[조건 분기 / Router] 오늘이 평일인가?
   │     ├─ 평일  → 메시지 = "📊 어제 총 사용자 N명 / 다운로드 N건"
   │     └─ 주말  → 메시지 = "🌿 주말입니다. 오늘 할 일 1개만 적어두기"
   │
   └─[Action] 카카오톡 '나에게 보내기' API 호출
        POST https://kapi.kakao.com/v2/api/talk/memo/default/send
        Authorization: Bearer {ACCESS_TOKEN}   (scope: talk_message)
        body: template_object = { object_type: "text", text: <분기된 메시지> }
```

- **Trigger 1개**: 정해진 시각(스케줄)
- **Action 2개 이상**: ① 메시지 텍스트 조립 ② 카카오 API 전송 (평일에는 GA 조회 Action이 추가됨)
- **조건 분기 1개 이상**: 평일/주말 라우팅 → 두 경로 모두 실제로 1회 이상 실행됨(아래 §5 실행 결과 참고)

> 구현 단계는 `build-guide.md` 참고. 본 문서는 비교 분석에 집중한다.

## 3. 도구별 구현 요약

### [도구 A] Apple 단축어 (Shortcuts)

- **트리거**: `개인용 자동화 → 특정 시각 → 매일 08:00 → 실행 전 묻기 끄기(즉시 실행)`
- **분기**: `현재 날짜 → 요일 구성요소 가져오기` → `If (토 또는 일)` 액션으로 평일/주말 텍스트 분기
- **전송**: `URL의 콘텐츠 가져오기(Get Contents of URL)` 액션으로 카카오 memo send 엔드포인트에 `POST`. 헤더에 `Authorization: Bearer ***`, 본문에 `template_object` 전달
- **토큰**: 카카오 access token을 단축어 내 텍스트 액션에 보관(또는 refresh token으로 갱신 호출 후 사용). HTTP 요청이라 Messages 앱 확인창 없이 무인 실행

> 스크린샷: `./screenshots/p1-shortcuts-overview.png` (자동화 목록), `./screenshots/p1-shortcuts-actions.png` (액션 구성)

### [도구 B] Make

- **트리거**: `Schedule` 모듈 — 매일 08:00 실행
- **분기**: `Router` + 각 경로에 `Filter` 조건(요일 = 평일 / 주말). 평일 경로엔 GA4 조회 모듈(HTTP) 추가
- **전송**: `HTTP > Make a request` 모듈로 카카오 memo send 호출. OAuth2 커넥션 또는 토큰 갱신용 HTTP 모듈을 앞단에 둠
- **토큰**: Make의 Connections에 카카오 OAuth2 커넥션을 저장하면 access token 갱신을 Make가 처리

> 스크린샷: `./screenshots/p1-make-scenario.png` (시나리오 캔버스), `./screenshots/p1-make-router.png` (Router/Filter)

## 4. 비교 분석 (9개 항목)

| # | 비교 항목 | Apple 단축어 (Shortcuts) | Make |
|---|---|---|---|
| 1 | **UI/UX** | 모바일 네이티브 액션 리스트(세로 스택). 손가락으로 액션 추가 | 웹 캔버스에 노드를 선으로 연결(시각적 플로우). 분기가 한눈에 보임 |
| 2 | **설정 난이도** | 액션 자체는 쉬우나 HTTP/JSON 본문 직접 작성은 다소 까다로움 | 모듈 검색·연결은 직관적. Router/Filter 개념 학습 곡선 약간 |
| 3 | **트리거 방식** | 기기 로컬의 "특정 시각" 개인 자동화 | 클라우드 cron 스케줄(서버에서 실행) |
| 4 | **기기 의존성** | ⚠️ 내 iPhone/Mac이 켜져 있고 자동화 권한이 있어야 실행 | ✅ 기기와 무관, 24시간 클라우드에서 실행 |
| 5 | **연동 서비스 범위** | Apple 생태계 액션 풍부 + HTTP로 외부 API 호출 가능(범용성은 제한적) | 2,000+ 앱 커넥터 + HTTP 모듈. 연동 폭이 압도적 |
| 6 | **무료 플랜 범위** | 완전 무료(기기 기본 제공) | 무료 1,000 ops/월 — 하루 1회 + 분기/조회 ≈ 월 60~120 ops로 여유 |
| 7 | **실행 로그/실패 확인** | 빈약함. 자동화 실행 이력·에러 추적이 어려움 | ✅ 시나리오별 실행 히스토리에서 모듈 단위 입출력·에러 확인 |
| 8 | **인증/토큰 관리** | access token을 직접 보관·갱신해야 함(refresh 호출 수동 설계) | OAuth2 커넥션이 토큰 갱신을 자동 처리 |
| 9 | **조건 분기 구현** | `If` 액션(단순 분기) | `Router` + `Filter`(다중 경로·복합 조건에 강함) |

## 6. 장단점 정리

### Apple 단축어
- **장점**: 완전 무료 / 추가 가입 없음 / 내가 원하는 시각·기기에서 즉시 실행 / 개인 데이터가 기기 밖으로 안 나감
- **단점**: 기기가 켜져 있어야 함 / 실행 로그·실패 알림이 부실 / 토큰 갱신을 직접 설계 / 복잡한 분기·다단계 연동엔 한계

### Make
- **장점**: 기기 무관 24시간 실행 / 모듈 단위 실행 로그 / OAuth 토큰 자동 갱신 / 광범위한 커넥터 / Router로 복잡한 분기 설계 용이
- **단점**: 무료 ops 한도 존재 / 외부 SaaS 의존(서비스 장애 시 영향) / 데이터가 클라우드를 경유

## 7. 어떤 상황에 적합한가 (의견)

- **단축어가 적합**: 나 혼자 쓰는 개인용 자동화, 무료로 끝내야 할 때, 기기가 늘 켜져 있고(예: 항상 켜둔 Mac) 외부 SaaS에 데이터를 안 보내고 싶을 때. "내가 원하는 시각에 나에게 카톡" 같은 **로컬·개인 트리거**에 강하다.
- **Make가 적합**: 실행이 빠지면 안 되는 업무용 자동화(클라우드 24h), 여러 서비스를 엮어야 할 때, 실패 추적·로그가 중요할 때, 토큰/인증을 안정적으로 굴려야 할 때.

**결론**: 같은 카카오 API라도 "기기 켜져 있을 때 나만 받으면 되는 핑"은 단축어가 가볍고, "절대 빠지면 안 되고 로그·연동이 필요한 파이프라인"은 Make가 안정적이다. 이번 GA 핑은 개인용이라 단축어로도 충분하지만, 빠짐 없는 운영 지표 알림으로 키운다면 Make로 옮기는 게 맞다.

## 8. 과금·연동 리스크 메모

- 두 구현 모두 **무료 범위**로 완수했다. Make는 무료 1,000 ops/월 안에서 동작(하루 1회 기준 월 60~120 ops).
- 카카오 '나에게 보내기'는 카카오 개발자 앱 등록만 하면 무료다(친구 전송이 아니라 본인 전송이라 별도 검수 불필요).
- **민감정보**: 카카오 REST API 키·access token, OAuth 토큰은 스크린샷·문서에서 `***`로 마스킹한다(§ 보안 제약 준수).
```
