## 🧭 입력 템플릿 (재사용)

```
[작업] A(스토어 메타데이터) / B(인앱 모달) / 둘 다
[앱] (이름 — 한 줄 정의)   [차별점] (1~3개)
[플랫폼] iOS/Android/둘 다   [단계] 출시 전/직후/성장기
# A일 때 → [대상 로케일]
# B일 때 → [가용 모달] [추적 상태(오픈횟수·설치후일수·프리미엄·리뷰함·공유함·기능사용)] [페이월 유무]
[톤] (예: 차분·정직)   [금지어] (예: 보정·외모등급)
[규칙] 정보 부족 시 최대 3개 확인 질문. 최종 답변엔 핵심 근거 3개만.
```

## 🛡️ 안전·윤리

- 사실/수치/정책은 "근거 제시 또는 확인 필요" 규칙(환각 방지). 검증된 사실(키워드 100자·리뷰 365일 3회 등)만 단정.
- 개인정보(실명·연락처·계정)는 프롬프트·로그에 포함하지 않는다.
- 다크패턴(첫 실행 권한·구매·리뷰 스택, 부정 순간 리뷰) 금지. 외모 평가·등급 표현 금지.
