# 나만의 프롬프트 관리 (Prompt Vault CLI)

Python 표준 라이브러리만으로 만든 콘솔 기반 프롬프트 관리 프로그램이다. 터미널에서
메뉴 번호를 입력해 프롬프트를 추가·조회·검색·즐겨찾기 관리할 수 있다.

## 실행 방법

```bash
# Python 3.10 이상 필요 (개발 환경: Python 3.14.4)
python3 prompt_manager.py
```

실행하면 메뉴가 출력되고, 번호를 입력해 기능을 선택한다. `0`을 입력하면 종료된다.
잘못된 번호를 입력하면 안내 메시지 후 메뉴로 돌아온다.

프로그램 실행 중 추가한 프롬프트와 즐겨찾기 상태는 **종료 시 초기화**된다
(영속화가 필요하면 아래 "JSON 저장/불러오기" 기능을 사용한다).

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목·내용·카테고리를 입력받아 새 프롬프트를 등록한다. 빈 값은 재입력을 요청한다. |
| 2 | 프롬프트 목록 | 전체 프롬프트를 번호·카테고리·즐겨찾기(⭐)와 함께 출력한다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하면 해당 카테고리의 프롬프트만 출력한다. |
| 4 | 프롬프트 검색 | 키워드가 제목/내용에 포함된 프롬프트를 검색한다. |
| 5 | 프롬프트 상세 보기 | 번호로 프롬프트의 전체 내용을 조회한다. 조회할 때마다 조회수가 1 증가한다. |
| 6 | 즐겨찾기 관리 | 번호로 즐겨찾기를 추가/해제(toggle)한다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아본다. |
| 8 | 프롬프트 수정 (보너스) | 제목·내용·카테고리를 수정한다. 빈 값은 기존 값을 유지한다. |
| 9 | 프롬프트 삭제 (보너스) | 확인(y/N) 후 프롬프트를 삭제한다. |
| 10 | 조회수 Top 목록 (보너스) | 상세 보기 조회수 기준 상위 5개를 정렬해 보여준다. |
| 11 | JSON으로 저장 (보너스) | 현재 프롬프트 전체를 `prompts.json`에 저장한다. |
| 12 | JSON에서 불러오기 (보너스) | `prompts.json`을 읽어 현재 목록을 대체한다. |
| 13 | 카테고리별 Markdown 내보내기 (보너스) | 카테고리별로 `export/*.md` 파일을 생성한다. |
| 0 | 종료 | 프로그램을 종료한다. |

## 카테고리

미리 정의된 카테고리는 다음 6종이며, 프롬프트 추가/수정 시 목록에 없는 이름을 직접
입력해 새 카테고리를 만들 수도 있다.

- **텍스트 생성** — 블로그·카피 등 텍스트 산출물을 만드는 프롬프트
- **이미지 생성** — 이미지 생성 AI(스크린샷, 그래픽 등)용 프롬프트
- **영상 생성** — 영상/스토리보드용 프롬프트
- **페르소나** — 에이전트/캐릭터의 역할·말투·금지사항을 정의하는 프롬프트
- **자동화** — 조건에 따라 동작을 결정하는 규칙/워크플로 프롬프트
- **기타** — 위 분류에 속하지 않는 프롬프트

## 기본 데이터

프로그램 시작 시 이전 미션(`b1-1`: 앱 컨버전 카피 에이전트 "프로모" 프롬프트 패키지)에서
실제로 작성한 프롬프트 4개가 기본 데이터로 등록되어 있다.

1. 앱스토어 메타데이터 생성 프롬프트 (텍스트 생성)
2. 인앱 모달 시퀀싱 결정 프롬프트 (자동화)
3. 앱스토어 히어로 스크린샷 이미지 프롬프트 (이미지 생성)
4. 프로모(Promo) 페르소나 정의 프롬프트 (페르소나)

## 코드 구조

`prompt_manager.py` 한 파일에 기능별 함수를 분리해 구현했다.

- `show_menu`, `input_nonempty`, `select_category`, `get_prompt_by_number` — 공용 유틸
- `add_prompt`, `show_list`, `show_by_category`, `search_prompt`, `show_detail`,
  `toggle_favorite`, `show_favorites` — 필수 기능
- `edit_prompt`, `delete_prompt`, `show_top`, `save_to_json`, `load_from_json`,
  `export_markdown` — 보너스 기능
- `main` — 메뉴 루프 및 함수 라우팅

## Git 작업 방식

- `main` 브랜치 외에 `feature/prompt-list` 브랜치를 생성해 "프롬프트 목록" 기능을
  구현한 뒤 `--no-ff` 병합으로 이력을 남겼다.
- 기능 단위(추가/목록/카테고리/검색/상세/즐겨찾기/CRUD/조회수/JSON/Markdown)로
  커밋을 나눴다.
- `git pull`로 원격과 동기화하고, 공개 샘플 저장소(`octocat/Hello-World`)를
  `git clone`으로 내려받아 구조와 로그를 확인한 뒤 삭제했다.
