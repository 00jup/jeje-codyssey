Threads 운영 작업대

쓸 말은 있는데
첫 문장이 안 나올 때.

소재 한 줄을 넣으면 타래 초안이 나온다. 댓글을 붙여 넣으면 답글 초안이 두 벌 나온다. 초안까지만 만든다 — 올리는 건 사람이 한다.

타래 지으러 가기 어떻게 쓰나

  • 지어내지 않는다

    소재에 없는 숫자·날짜·성과는 쓰지 않고 [여기에 숫자]로 자리를 비운다. 빈칸이 거짓말보다 낫다.

  • 500자를 지킨다

    Threads 한 글의 상한이다. 넘기면 게시 자체가 막히므로 서버에서 잘라서 준다.

  • 댓글의 언어로 답한다

    원글이 한국어여도 댓글이 영어면 영어로 답글을 만든다. 국가가 아니라 글자를 본다.

  • 게시는 사람이 한다

    자동 게시가 없다. 맥락을 놓친 답글이 공개로 남는 게 안 다는 것보다 나쁘다.

답글 짓기

받은 댓글을 붙여 넣으면 짧은 답과 자세한 답, 두 벌이 나온다.

사용법

  1. 소재를 사실로 적는다

    "열심히 만들었다" 보다 "2만 장 도는 데 40초 → 4초" 가 낫다. 초안의 질은 거의 전부 여기서 갈린다.

  2. 대괄호를 확인한다

    [여기에 숫자] 가 보이면 그 자리는 모델이 모르는 값이다. 지어내는 대신 비워 둔 것이니 직접 채운다.

  3. 조각마다 복사해서 올린다

    Threads 는 조각을 하나씩 이어 올린다. 조각 오른쪽 복사 버튼을 쓴다.

  4. 답글은 두 벌 중 고른다

    짧은 쪽과 자세한 쪽은 길이만 다른 게 아니라 어디까지 설명하느냐가 다르다.

자주 묻는 것

내 글이 어딘가 저장되나?

저장하지 않는다. 입력은 요청 한 번 처리하는 동안만 메모리에 있고, 서버 액세스 로그도 꺼 두었다. 결과는 브라우저 화면에만 남아서 새로고침하면 사라진다.

Threads 계정을 연결해야 하나?

아니다. 로그인도 계정 연결도 없다. 이 서비스는 글을 대신 올리지 않고 초안만 만든다. 붙여넣기는 사람이 한다.

결과가 마음에 안 들면?

소재를 더 구체적으로 적고 다시 만든다. 같은 소재로 다시 눌러도 매번 다른 초안이 나온다.

"지금 요청이 몰렸습니다" 가 뜬다

AI API 호출 한도(429)에 걸린 것이다. 30초쯤 뒤에 다시 시도하면 된다. 무료 등급 키를 쓰기 때문에 분당 호출 수에 제한이 있다.

영어 댓글도 되나?

된다. 답글은 댓글에 쓰인 언어로 나온다. 원글이 한국어여도 댓글이 영어면 영어로 답한다.

소개

혼자 앱을 만들면 만드는 시간보다 알리는 시간이 더 어렵다. 쓸 얘기는 늘 있는데 첫 문장에서 20분이 지나간다. 타래공방은 그 20분을 없애려고 만들었다.

왜 자동 게시가 없나

답글은 공개로 남는다. 맥락을 놓친 정중한 문장이 자동으로 나가면 안 단 것보다 나쁘다. 그래서 이 서비스는 초안에서 멈춘다. 사람이 읽고, 고치고, 올린다.
