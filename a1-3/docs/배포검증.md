실제 생성에 사용한 이름은 테스트용 **민준 / 지수**다. 사진은 **PHOTO TEST**라고
쓴 테스트 이미지이며 개인 사진을 사용하지 않았다. 입력 전문과 출력은
[README](../README.md)에 있다. 공유 편지는 생성 후 30일이면 만료된다.

## 로컬·대체 응답 검증

다음은 실제 AI·Redis 호출과 구분되는 로컬 검증이다.

- Python 및 JavaScript 문법, Vercel 방식의 엔드포인트 모듈 import 성공.
- AI와 Redis를 대체한 HTTP 검증: 잘못된 입력·JSON·예약 주소·2 MiB 초과 요청을
  차단하고, 입력 검증 실패 시 AI를 호출하지 않음.
- 같은 대체 응답 검증에서 **236,904바이트 사진 요청 → HTTP 200**.
  기존 64 KiB 제한을 넘는 사진 요청이 수정 후 처리됨을 확인했다.
- 로컬 서버의 환경 파일 및 인코딩된 숨김 경로 차단, 홈과 CSS 제공 확인.
- API 오류와 타임아웃 처리 코드는 구현되어 있다. 실제 제공자 장애나 30초 지연을
  의도적으로 일으키지는 않았다.

## 발견한 문제와 수정

| 문제 | 수정 / 확인 |
| --- | --- |
| 이전 타래공방 코드가 기본 폴더에 남음 | 여행 초대 사이트 거부불가 버전을 main에 반영 |
| 이전 Upstash 주소의 DNS 실패 | 새 Production 환경 변수 등록 후 실제 저장·조회 성공 |
| GPT 인증 실패 | 사용자 선택에 따라 Claude만 사용 |
| 배포 방식에서 `_shared` import 실패 | 공통 모듈을 읽기 전에 경로 설정, 배포 성공 |
| 사진 허용량과 64 KiB 요청 제한 불일치 | 2 MiB로 조정, 큰 사진 요청 검증 및 실제 사진 저장 성공 |
| 로컬 환경 파일 정적 제공 | 숨김 경로 차단, `.vercelignore` 설정 |

AI가 입력에 없는 문장을 추가할 수 있다. 긴 입력 결과에 “짐 준비는 내가 챙길
테니까”가 추가된 사실을 README에 기록했다. 생성 결과는 공유 전에 미리보기로
확인한다. 공개 API 전체에 적용되는 서버 호출 빈도 제한은 아직 없다.
