## 실제로 확인하고 수정한 내용

1. 저장소 기본 작업 폴더에는 이전 ‘타래공방’만 있고, `.claude/worktrees/a1-3-v2`
   작업 폴더에 새 ‘거부불가’ 코드가 미커밋 상태로 있었다. 올바른 코드를 확인해
   이 버전을 배포 대상으로 삼았다.
2. Vercel처럼 파일을 모듈로 불러오면 공통 모듈 `_shared`를 찾지 못하는 문제를
   재현했다. 각 엔드포인트에서 공통 모듈 import **전에** 해당 폴더를 경로에 추가했다.
3. 사진 2장을 허용하면서 HTTP 본문 상한은 64 KiB인 불일치를 수정해 2 MiB로
   조정했다. 사진이 들어간 큰 요청의 회귀검증은 AI와 Redis를 대체한 테스트로 확인했다.
4. 로컬 개발 서버가 환경 파일을 정적 파일로 제공하지 않도록 숨김 경로를 차단했다.
   Vercel 업로드에는 `.vercelignore`로 환경 파일·가상환경·증빙을 제외했다.
5. 실제 Claude API 호출에서 제목·본문·재치 대사 8개를 확인했다. GPT 인증 오류를
   확인하고 사용자 선택에 따라 최종 버전은 Claude만 사용하도록 정리했다.
6. Vercel에 Python 3.12를 지정하고 실제 빌드를 통과시켰다. 사용자 로그인·GitHub
   앱 권한 설정 뒤 저장소 연결을 완료하고, Root Directory를 `a1-3`로 지정했다.
7. 실제 배포 화면에서 1440px·390px 뷰포트와 메뉴 이동을 확인했다. 최종 API와
   공유 링크 검증 결과 및 화면 캡처는 [배포 검증 기록](./배포검증.md)에 있다.

과제의 AI 코딩 도구 증빙은 이 대화 발췌와 이전 [개발 과정 기록](./ai-coding-log.md)을
제출한다. 추가 화면 캡처가 필요하면 이 실제 대화를 촬영할 수 있다.
