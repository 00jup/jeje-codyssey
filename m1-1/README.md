## 📌 프로젝트 개요

본 프로젝트는 2023년부터 2024년까지 2개년 동안의 **삼성전자(005930.KS)** 일별 주가 시계열 데이터를 바탕으로 트렌드(추세), 이동평균선 크로스오버, 롤링 변동성, 월별 계절성을 분석하고 데이터 기반의 인사이트를 도출한 분석 프로젝트입니다.

- **분석 대상**: 삼성전자 (`005930.KS`)
- **데이터 출처**: Yahoo Finance
- **데이터 기간**: 2023-01-01 ~ 2024-12-31 (총 489개 거래일)
- **주요 결과물**:
  - 심층 분석 리포트 ([`REPORT.md`](./REPORT.md))
  - 고해상도 시계열 시각화 6종 ([`images/`](./images/))
  - 분석 파이썬 스크립트 ([`analysis.py`](./analysis.py)) 및 주피터 노트북 ([`analysis.ipynb`](./analysis.ipynb))
  - 탐색형 웹 대시보드 ([`app.py`](./app.py) - Streamlit)

## 🚀 빠른 시작 (Quick Start)

### 1. 환경 설정 및 의존성 설치
```bash
cd m1-1
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. 환경 변수 설정 (선택 사항)
기본값이 설정되어 있어 생략 가능하지만, 티커나 경로를 변경하려면 `.env` 파일을 복사하여 수정합니다.
```bash
cp .env.example .env
```

### 3. 분석 스크립트 실행 (시각화 이미지 6종 및 데이터 자동 생성)
```bash
python analysis.py
```
> 실행 시 터미널에 요약 통계가 출력되고 `data/` 및 `images/` 폴더에 파일이 자동 생성됩니다.

### 4. 주피터 노트북 실행
```bash
jupyter notebook analysis.ipynb
```

### 5. Streamlit 웹 대시보드 실행 (보너스 과제 1)
```bash
streamlit run app.py
```
> 브라우저(`http://localhost:8501`)에서 기간 슬라이더, 이동평균선 선택, 이벤트 하이라이트 토글을 자유롭게 탐색할 수 있습니다.

## 💡 주요 인사이트 요약 (상세 내용은 [REPORT.md](./REPORT.md) 참조)

1. **2024년 하반기 -43% 폭락과 이동평균 데드크로스의 조기 경보**:
   - 20일선이 60일·120일선을 하향 돌파한 8월 초 데드크로스는 단순한 단기 조정을 넘어선 장기 역배열 하락장의 강력한 선행 신호였습니다.
2. **변동성 스파이크(50.8%)와 대량 거래량의 바닥(Capitulation) 신호**:
   - 49,900원 기록 직후 10조 원 자사주 매입 발표와 함께 거래량이 평시의 3배 이상 폭발하며 강력한 하방 지지선을 형성했습니다.
3. **월별 수익률의 3분기(8~9월) 취약성**:
   - 여름 휴가철 유동성 축소와 2분기 실적 발표 이후의 가이던스 하향이 맞물려 2개년 연속 8월 마이너스 수익률 및 2024년 3분기 누적 -30% 이상 급락이 집중되었습니다.
