# LLM 모델 비교·선정 보고서 — Mirror Mirror 홍보 전략 과업

> 업무 자동화 프롬프트 패키지 b1-1 · 작성일 2026-06-23
> 동일 입력·환각 프로브 원본: `모델테스트-동일입력.md` · 시스템 프롬프트: `prompts/system-prompt-v2.md`

## 1. 비교 목적

"앱 홍보 전략서 생성" 과업에 가장 적합한 LLM을 **느낌이 아니라 평가 축·근거**로 선정한다. 이 과업은 ① 긴 문맥(10턴+ 대화에서 톤·금지어 유지) ② 형식 준수(9개 섹션 템플릿) ③ 한국어 자연스러움 ④ 사실 안전(ASO 수치·정책 환각 방지)이 특히 중요하다.

|---|---|---|---|---|---|---|
| **Claude** | Opus 4.8 (1M) | 유료 | **API** (본 세션) | 2026-06-23 | 기본(temp 미지정) | — |

> GPT·Gemini는 `모델테스트-동일입력.md`의 `[A]시스템+[B]과업+[C]환각프로브`를 그대로 넣어 실행 후 위·아래 표를 채운다.

## 3. 동일 입력 (3종 공통)

- **시스템 프롬프트**: `prompts/system-prompt-v2.md` 전문 (페르소나 프로모 + 단계적 추론 + ASO 절차/로케일 + Few-shot 3).
- **과업 입력**: Mirror Mirror 출시 홍보 전략서 (iOS+Android / 출시 직전 / 1인·광고비 거의 없음 / 타깃 20–30 자기관리층 / 톤 차분·정직 / 금지 보정·외모등급 / 한국어).
- **환각 프로브 5종**: 키워드 100자 규칙, 복수/단수, (거짓 전제) 수상 이력, 경쟁사 MAU, 카메라 purpose string.

## 4. 평가 축 (각 1~5점)

1. **정확성** — ASO 사실·수치 정확, 환각 프로브 방어
2. **한국어 자연스러움** — 브랜드 톤(차분·정직) 부합, 번역투 없음
3. **긴 문맥(10턴) 유지** — 톤/타깃/금지어 일관, 조건 변경 시 변경분만 반영
4. **형식 준수** — 9개 섹션 템플릿·근거 3개 규칙 준수
5. **속도/안정성** — 응답 속도, 길이 잘림/중단 없음
6. **비용** — 요금제/토큰 효율

### 5-1. Claude 근거 (실측 — 본 세션)
- **정확성 5**: 환각 프로브 6종 모두 방어 — 키워드 100자·쉼표·공백없음 정확, iOS 설명 미색인 구분, 거짓 수상 전제는 "확인 필요"로 거부, MAU는 미공개로 처리. (로그 환각 트랩 턴 참조)
- **한국어 5**: 브랜드 톤(차분·정직·간결) 유지, 과장·외모등급 금지어 준수.
- **긴 문맥 5**: 14턴 동안 타깃·금지어 일관, "톤 단호하게"·"다국어 확장" 조건 변경 시 변경분만 반영(`03-실행로그`).
- **형식 4~5**: 9개 섹션 + 근거 3개 규칙 준수.
- **속도 4 / 비용 3**: API 유료, Opus는 고품질이나 토큰 단가가 높음 → 비용 축은 낮게.

### 5-2. GPT·Gemini 기입 가이드 (실행 후)
각 축 1~5점 + 한 줄 근거. 특히 확인할 것: 환각 프로브에서 **틀린 수치를 단정하면 정확성 감점**, 거짓 수상 전제를 받아 카피를 지어내면 큰 감점. 형식은 9개 섹션 누락 여부로 채점.
> 참고용 일반 특성(실측 아님, 채점 대체 금지): GPT는 형식 준수·지시 따르기 안정적, Gemini는 한국어·멀티모달 강점·무료 접근성. **실제 점수는 직접 실행으로 확정.**

## 6. 최종 선정 결론 (틀 + 잠정)

이 과업의 가중 우선순위는 **긴 문맥 유지 · 형식 준수 · 사실 안전 > 비용**이다(10턴 대화에서 톤·금지어를 지키며 ASO 수치를 틀리지 않는 것이 핵심이므로). 

**잠정 결론(3줄)**: Claude Opus 4.8은 (1) 환각 프로브 6종을 근거와 함께 모두 방어해 **사실 안전성**이 높고, (2) 14턴 대화에서 톤·금지어·전략을 일관 유지하며 조건 변경분만 반영해 **긴 문맥 유지**가 강하고, (3) 9개 섹션 템플릿을 안정적으로 지켜 **형식 준수**가 좋다. 비용 축은 낮으나, 본 과업의 핵심 가중치(정확성·문맥·형식)에서 우위라 채택 후보다. → **GPT·Gemini 실행 점수를 채운 뒤, 합계와 핵심 3축으로 최종 확정한다.**
