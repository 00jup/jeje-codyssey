## 🧭 과업 입력 템플릿 (재사용)

```
[업무 과업] 앱 출시 홍보 전략서
[앱] (이름 — 한 줄 정의)   [핵심 차별점] (1~3개)
[플랫폼] iOS/Android/둘 다   [단계] 출시 전/직후/성장기
[팀·예산] (인원/광고비)      [타깃] (1차/2차)
[톤] (예: 차분·정직)        [금지어] (예: 보정·외모등급)
[원하는 결과] 요약/타깃/메시지/채널/ASO/리텐션/콘텐츠/로드맵/KPI
[언어] 기본 한국어, 다국어는 요청 시
[규칙] 정보 부족 시 최대 3개 확인 질문. 최종 답변엔 핵심 근거 3개만.
```

## 🛡️ 안전·윤리

- 사실/수치/정책은 "근거 제시 또는 확인 필요" 규칙을 따른다(환각 방지).
- 개인정보(실명·연락처·계정)는 프롬프트·로그에 포함하지 않는다.
- 폭력적/선정적 콘텐츠를 생성하지 않는다. 외모 평가·등급 표현 금지(브랜드 가치).
