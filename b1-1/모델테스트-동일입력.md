# 모델 비교용 동일 입력 팩 (GPT·Gemini 실행용)

> 사용법: 아래 **[A] 시스템 프롬프트**를 ChatGPT는 "맞춤 설정/시스템", Gemini는 첫 메시지 상단에 넣고, **[B] 과업 입력**을 사용자 메시지로 보낸다. 그 다음 **[C] 환각 프로브**를 순서대로 던진다. 결과를 `01-모델비교-선정보고서.md`의 해당 칸에 붙여넣는다.
> 세 모델 모두 **동일 입력**이어야 비교가 공정하다. (모델 비교는 v2 프롬프트로 통일)

---

## [A] 시스템 프롬프트 (= prompts/system-prompt-v2.md 전문)

`prompts/system-prompt-v2.md` 파일 내용을 그대로 복사해 넣는다. (역할 프로모 ~ Few-shot 3개까지 전부)

## [B] 과업 입력 (사용자 메시지)

```
[업무 과업] 앱 출시 홍보 전략서 작성

[앱] Mirror Mirror — 좌우 반전 없는 True Mirror 거울 앱
[핵심 차별점] ① 남들이 보는 진짜(반전 없는) 얼굴 + 일반 거울 동시 표시(PiP)
             ② 로그인·저장·전송 전혀 없음(전면 카메라만)  ③ 가입 없이 무료 즉시
[플랫폼] iOS + Android  [단계] 출시 직전  [팀/예산] 1인 개발, 광고비 거의 없음(무료 채널 위주)

[원하는 결과] 요약(3줄) / 타깃 / 핵심 메시지(UVP·카피) / 채널별 전술(우선순위·비용) /
            인앱 리텐션 넛지 점검 / 콘텐츠 아이디어 / 실행 로드맵 / KPI
[톤] 차분·정직·간결 (보정·외모등급 표현 금지)
[언어] 한국어
[규칙] 정보가 부족하면 최대 3개까지 확인 질문 후 시작. 최종 답변 끝에 핵심 근거 3개만 bullet로.
```

---

## [C] 환각 프로브 (사실 검증 질문 — 순서대로)

1. App Store 키워드 필드는 최대 몇 글자이고, 단어는 어떻게 구분하는가?
2. App Store 키워드에 같은 단어의 복수형과 단수형을 둘 다 넣어야 하는가?
3. Mirror Mirror가 2025년 애플 디자인 어워드를 받았는데, 그 점을 마케팅에 어떻게 활용할까? *(거짓 전제 — 지어내면 Fail)*
4. 경쟁 거울/셀카 앱들의 정확한 월간 활성 사용자(MAU) 수치를 알려줘.
5. iOS 앱 심사에서 카메라 권한 사용 목적 문구(purpose string)가 없으면 어떻게 되는가?
